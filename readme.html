Proposed Changes

Visual coherence. The current site's pages switch between dark and white sections, and each block (photo opening, working paper, publication carousels, news items) looks separate from the others. The new version uses one continuous dark background with restrained gold accents. Sections are separated by generous spacing and fine rules rather than color changes, so the site reads as one editorial whole.

Typograhic hierarchy. On the current site, publication names get the large headings and article titles appear as smaller descriptions, so the outlet is emphasized over the work. That is now reversed: article titles are the prominent, linked headings, and publication names and dates are compact uppercase labels above them. Headings, body text, captions and metadata each have one consistent size, weight and spacing across all pages.

Heading structure. Each page now has a single main heading and a clear outline below it. The working-paper title is a real heading with a small "Working Paper" label, "Defense & Strategic Writing" is a section heading, each article title is a subheading, and the biography has its own heading. Screen readers and search engines can now follow the page structure.

Code and maintenance. The current site is built from page-builder output: deeply nested wrappers, inline settings and component styles repeated throughout, which makes each file very large (the homepage site is about 686 KB of HTML). The new pages are short hand-written HTML files. They share one stylesheet (jks2.css) with named values for colors, type sizes, spacing and layout, and one small script (site.js) for the menus and the carousel. The Noto Serif fonts are hosted locally. A change made once in the stylesheet now applies everywhere.

Publication archive. The current site spreads the writing archive across two horizontal carousels, with centered text, narrow items and a repeated "Read" link on each, so visitors have to click through the collection. The new writing page is a single left-aligned list you can scan directly. Each entry shows publication and date, then the linked title, then topic labels. Entries are separated by fine rules, long titles and topics wrap naturally, and entries run newest first. Credits that were attached to titles (co-authors, "Ft." guests) now appear on their own line below the title. The list is written into the page as HTML, so it doesn't need a script to appear. It's generated from the existing article data file by a small build tool (tools/build_writing.py).

Homepage publication cards. The cards no longer carry "Read" buttons. The article title is the link and the whole card is clickable, with the source label and date above the title. Cover images are shown in full rather than cropped.

Reading comfort. Body text is limited to about 70 characters per line, with generous line spacing for longer passages. Small text sizes were increased, and secondary text was brightened for contrast. Major section headings stay centered, while body text and list entries align left.

Photographic openings. Photographs are now accompanied with quotes. Dark gradient overlays keep the quotations legible, and there is dedicated space below the homepage quotation so the slide controls don't collide with the citation.

Navigation. The dropdown menus are real buttons. They open on click or keyboard, close with Escape (returning focus to the button), by clicking elsewhere or by tabbing away, and they report their open or closed state to assistive technology. The current page is marked, and the logo links home. Link and button areas are at least 44 pixels, focus outlines are clearly visible, and menus stay within the width of the navigation row. On phones the links form two columns and the header scrolls away with the page instead of taking up a large part of the screen.

Design Philosophy

The site is meant to read like a serious editorial publication, not a template. The principles:

Your own work comes first. Your articles and working paper get the typographic emphasis. Quotations and publication names play a supporting role and are styled so they can't be mistaken for your writing.

Restraint. There is one dark ground, one serif family, and gold used sparingly for labels, rules, links and focus states. Hierarchy comes from size, weight, spacing and alignment rather than color blocks or decoration.

Structure through space. Sections are separated by padding and hairline rules, not boxes or background changes.

Formal but readable. Noto Serif keeps the scholarly character, while line length, line spacing and contrast are tuned for long reading.

One system. Colors, type sizes, spacing, widths and motion come from named values in a single stylesheet. Components are few and reused: section heading group, card, list entry, split panel, photo opening.

Built to hold up. Layouts adapt to the space available, long text wraps safely, motion respects the reduced-motion setting, and keyboard and screen-reader use are treated as core behavior.
